Credence Charter Bus — logo files (SVG, scalable to any size)

credence-logo.svg              Combined lockup: bus mark + wordmark, for light backgrounds
credence-mark.svg              Bus mark only (transparent background)
credence-wordmark.svg          Wordmark only ("Credence / CHARTER BUS"), for light backgrounds
credence-logo-on-navy.svg      Combined lockup on the brand navy background
credence-wordmark-on-navy.svg  Wordmark on the brand navy background

Notes
- All text is converted to outlines, so the files render identically everywhere
  (no fonts need to be installed). Typefaces used: Bitter Bold and
  Source Sans 3 SemiBold, both open-licensed (SIL OFL).
- Brand colors: navy #1B2A4A, cream #F7F5F0, bronze #C1A15A
  (dark bronze #7A612A is used for the small text on light backgrounds).
- The "-on-navy" files include a solid navy rectangle so they preview correctly;
  delete that rectangle in any vector editor if you need a transparent version.
